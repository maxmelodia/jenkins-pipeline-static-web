# jenkins-pipeline-static-web
Pipeline as Code

A tarefa consiste em criar um Jenkinsfile (ou de qualquer outra ferramenta) , que seja possível ser executado e que contenha os seguintes recursos:
    Agent
    Variáveis de ambiente
    Options
    Parameters
    Trigger
    Post actions
    Steps
    Input
    Conditions (when, not ou equals)
    Credenciais
    Parallel Stages
    Matrix

Deve ser entregue o arquivo e, caso seja necessário instalar algum plugin para sua pipeline funcionar, uma listagem destes plugins.
